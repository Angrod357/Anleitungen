Plex-Server einrichten
Raspberry Pi 5 mit grafischer Oberfläche (Desktop) als vollständiger Medienserver — Plex, qBittorrent, Sonarr, Radarr, Prowlarr und Overseerr installieren und verbinden.
Überblick
Wie alles zusammenspielt
Architektur
ToolFunktionPortVerbindet mit
Plex Media ServerMedien streamen auf TV, Handy, Browser32400Dateisystem
qBittorrentDownload-Client — lädt Torrents herunter8080Sonarr, Radarr
ProwlarrIndexer-Manager — durchsucht Torrent-Quellen9696Sonarr, Radarr
SonarrAutomatischer Download von Serien8989Prowlarr, qBittorrent, Plex
RadarrAutomatischer Download von Filmen7878Prowlarr, qBittorrent, Plex
OverseerrWeb-UI um Serien/Filme anzufragen5055Sonarr, Radarr, Plex
🔄
Ablauf: Du fragst in Overseerr einen Film an → Radarr sucht via Prowlarr nach einem Torrent → qBittorrent lädt ihn herunter → Radarr verschiebt die Datei in den Mediaordner → Plex erkennt sie automatisch und zeigt sie in deiner Bibliothek.

Raspberry Pi OS Desktop (nicht Lite) auswählen im Imager — du brauchst die grafische Oberfläche für die erste Plex-Einrichtung im Browser. Raspberry Pi Imager → Gerät: Pi 5 → OS: Raspberry Pi OS (64-bit) mit Desktop.
# Nach erstem Boot — System aktualisieren $ sudo apt update && sudo apt upgrade -y && sudo apt autoremove -y # Festplatte einbinden (Abschnitt Heim-NAS für Details) $ sudo mkdir -p /mnt/media/{filme,serien,downloads} $ sudo chown -R $USER:$USER /mnt/media
Schritt 01
Plex Media Server installieren
Terminal
# Plex-Repository hinzufügen $ curl https://downloads.plex.tv/plex-keys/PlexSign.key | gpg --dearmor | \ sudo tee /usr/share/keyrings/plex.gpg > /dev/null $ echo "deb [signed-by=/usr/share/keyrings/plex.gpg] \ https://downloads.plex.tv/repo/deb public main" | \ sudo tee /etc/apt/sources.list.d/plexmediaserver.list # Plex installieren $ sudo apt update $ sudo apt install plexmediaserver -y # Dienst aktivieren & starten $ sudo systemctl enable --now plexmediaserver # Status prüfen $ sudo systemctl status plexmediaserver
1
Browser auf dem Pi öffnen (Chromium) → http://localhost:32400/web
2
Plex-Konto erstellen oder einloggen auf plex.tv (kostenlos).
3
Server benennen: z.B. Pi-Plex → Weiter.
4
Bibliotheken hinzufügen: + Bibliothek hinzufügen → Typ Filme → Ordner /mnt/media/filme → Hinzufügen. Dasselbe für Serien mit /mnt/media/serien.
5
Plex ist jetzt erreichbar unter: http://<pi-ip>:32400/web
✅
Plex-App (kostenlos) auf TV, Handy oder Fire Stick installieren → Server automatisch gefunden → sofort streamen.
# Plex darf auf Medienordner zugreifen $ sudo chown -R plex:plex /mnt/media $ sudo chmod -R 755 /mnt/media
Schritt 02
qBittorrent-nox installieren (Web-UI)
Terminal

qBittorrent-nox ist die headless-Version — ohne grafische Oberfläche, nur mit Web-UI. Perfekt für den Pi.

# qBittorrent-nox installieren $ sudo apt install qbittorrent-nox -y # Systemd-Service erstellen $ sudo nano /etc/systemd/system/qbittorrent.service
# Inhalt der Service-Datei: [Unit] Description=qBittorrent-nox After=network.target [Service] Type=forking User=pi Group=pi ExecStart=/usr/bin/qbittorrent-nox -d --webui-port=8080 Restart=on-failure [Install] WantedBy=multi-user.target
# Dienst starten $ sudo systemctl daemon-reload $ sudo systemctl enable --now qbittorrent
1
Browser → http://localhost:8080 — Login: User admin / Passwort adminadmin
2
Einstellungen → Web UI: Passwort sofort ändern!
3
Einstellungen → Downloads: Standardpfad auf /mnt/media/downloads setzen.
4
Einstellungen → Downloads → Abgeschlossene Downloads verschieben nach: aktivieren. Sonarr/Radarr werden die Dateien selbst verschieben — Pfad leer lassen.
📌
Kategorien werden von Sonarr/Radarr automatisch gesetzt (sonarr / radarr). qBittorrent muss die Web-UI-Authentifizierung für localhost nicht deaktivieren — Sonarr/Radarr verbinden sich per API-Key.
Schritt 03
Prowlarr installieren (Indexer-Manager)
Terminal

Prowlarr verwaltet alle deine Torrent-Indexer an einem Ort und synchronisiert sie automatisch zu Sonarr und Radarr.

# Abhängigkeiten $ sudo apt install curl sqlite3 -y # Prowlarr herunterladen (aktuelle Version prüfen auf github.com/Prowlarr/Prowlarr) $ cd /tmp $ curl -L https://github.com/Prowlarr/Prowlarr/releases/latest/download/Prowlarr.master.linux-musl-arm64.tar.gz \ -o prowlarr.tar.gz $ tar -xzf prowlarr.tar.gz $ sudo mv Prowlarr /opt/prowlarr # Systemd-Service $ sudo nano /etc/systemd/system/prowlarr.service
[Unit] Description=Prowlarr After=network.target [Service] Type=simple User=pi Group=pi ExecStart=/opt/prowlarr/Prowlarr -nobrowser -data=/home/pi/.config/Prowlarr Restart=on-failure [Install] WantedBy=multi-user.target
$ sudo systemctl daemon-reload $ sudo systemctl enable --now prowlarr
1
Browser → http://localhost:9696
2
Indexers → Add Indexer → gewünschte Indexer hinzufügen (z.B. 1337x, EZTV, YTS für öffentliche Indexer).
3
Prowlarr API-Key notieren: Settings → General → API Key — wird für Sonarr/Radarr gebraucht.
Schritt 04
Sonarr installieren (Serien-Downloader)
Terminal
# Sonarr-Repository hinzufügen $ sudo apt install gnupg ca-certificates -y $ curl -fsSL https://mediaserver.tools/keys/sonarr.asc | \ sudo gpg --dearmor -o /usr/share/keyrings/sonarr.gpg $ echo "deb [arch=arm64 signed-by=/usr/share/keyrings/sonarr.gpg] \ https://apt.sonarr.tv/ubuntu focal main" | \ sudo tee /etc/apt/sources.list.d/sonarr.list $ sudo apt update $ sudo apt install sonarr -y # Alternativ — manuelle Installation (zuverlässiger auf Pi) $ cd /tmp $ curl -L https://services.sonarr.tv/v1/download/main/latest?version=4&os=linux&arch=arm64 \ -o sonarr.tar.gz $ tar -xzf sonarr.tar.gz $ sudo mv Sonarr /opt/sonarr
# Systemd-Service $ sudo nano /etc/systemd/system/sonarr.service
[Unit] Description=Sonarr After=network.target [Service] Type=simple User=pi Group=pi ExecStart=/opt/sonarr/Sonarr -nobrowser -data=/home/pi/.config/Sonarr Restart=on-failure [Install] WantedBy=multi-user.target
$ sudo systemctl daemon-reload $ sudo systemctl enable --now sonarr
1
Browser → http://localhost:8989
2
Settings → Media Management → Root Folders: /mnt/media/serien hinzufügen.
3
API-Key notieren: Settings → General → API Key.

Schritt 06
Overseerr installieren (Anfrage-Interface)
Terminal

Overseerr ist die schöne Benutzeroberfläche: Freunde und Familie können hier Filme und Serien anfragen, ohne Zugang zu Sonarr/Radarr zu brauchen.

# Node.js installieren (benötigt für Overseerr) $ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash - $ sudo apt install nodejs -y $ node --version ← sollte v20.x.x zeigen # Overseerr installieren $ sudo npm install -g overseerr # Oder via Docker (empfohlen auf Pi) $ docker run -d \ --name overseerr \ -e LOG_LEVEL=debug \ -e TZ=Europe/Zurich \ -p 5055:5055 \ -v /home/pi/.config/overseerr:/app/config \ --restart unless-stopped \ sctx/overseerr
1
Browser → http://localhost:5055
2
Mit Plex-Konto einloggen → Plex-Server auswählen (Pi-Plex).
3
Sonarr und Radarr verbinden (nächster Schritt).
Schritt 07
Alle Tools verbinden — die grosse Verkabelung
Wichtigster Schritt
① Prowlarr → Sonarr & Radarr verbinden
1
Prowlarr öffnen (:9696) → Settings → Apps → Add Application.
2
Sonarr hinzufügen: URL http://localhost:8989 · API-Key von Sonarr einfügen → Test → Save.
3
Radarr hinzufügen: URL http://localhost:7878 · API-Key von Radarr einfügen → Test → Save.
4
Prowlarr synchronisiert nun alle Indexer automatisch zu Sonarr und Radarr. Sync App Indexers klicken.
② Sonarr → qBittorrent verbinden
1
Sonarr (:8989) → Settings → Download Clients → Add → qBittorrent wählen.
2
Host: localhost · Port: 8080 · Username: admin · Password: dein Passwort · Category: sonarr.
3
Test → grüner Haken → Save.
③ Radarr → qBittorrent verbinden
1
Radarr (:7878) → Settings → Download Clients → Add → qBittorrent wählen.
2
Gleiche Einstellungen wie bei Sonarr — nur Category: radarr.
3
Test → Save.
④ Sonarr & Radarr → Plex verbinden
1
Sonarr (:8989) → Settings → Connect → Add → Plex Media Server.
2
Host: localhost · Port: 32400 · Authenticate with Plex.tv → Plex-Konto verbinden.
3
Dasselbe in Radarr wiederholen.
4
Jetzt scannt Plex automatisch die Bibliothek wenn Sonarr/Radarr neue Dateien hinzufügen.
⑤ Overseerr → Sonarr, Radarr & Plex verbinden
1
Overseerr (:5055) → Settings → Services → Add Radarr Server.
2
Hostname: localhost · Port: 7878 · API-Key von Radarr · Root Folder: /mnt/media/filme · Quality Profile: Any → Test → Save.
3
Add Sonarr Server: Port 8989 · API-Key von Sonarr · Root Folder: /mnt/media/serien → Test → Save.
🎉
Ab jetzt: in Overseerr nach einem Film suchen → anfordern → alles passiert automatisch → nach Download in Plex streamen.
Schritt 08
Desktop-Autostart & Dashboard einrichten
Desktop

Da du die grafische Oberfläche hast, kannst du einen Browser-Dashboard-Tab mit allen Web-UIs einrichten der beim Start automatisch öffnet.

# Autostart-Datei für Chromium erstellen $ mkdir -p ~/.config/autostart $ nano ~/.config/autostart/dashboard.desktop
[Desktop Entry] Type=Application Name=Plex Dashboard Exec=chromium-browser --new-window \ http://localhost:32400/web \ http://localhost:8989 \ http://localhost:7878 \ http://localhost:9696 \ http://localhost:8080 \ http://localhost:5055 Hidden=false NoDisplay=false X-GNOME-Autostart-enabled=true
💡
Chromium öffnet beim Login alle Web-UIs als Tabs: Plex · Sonarr · Radarr · Prowlarr · qBittorrent · Overseerr
📌
Für Remote-Zugriff: VPN (WireGuard) einrichten — sieh Heim-NAS Anleitung. Alle Ports sind dann von unterwegs erreichbar.
Diagnose
Alle Dienste verwalten
Terminal
# Status aller Dienste auf einmal prüfen $ for s in plexmediaserver qbittorrent prowlarr sonarr radarr; do echo "─── $s ───" sudo systemctl status $s --no-pager -l | grep -E "Active|Main" done # Alle auf einmal starten / stoppen / neu starten $ sudo systemctl restart plexmediaserver qbittorrent prowlarr sonarr radarr # Logs eines Dienstes live verfolgen $ journalctl -u sonarr -f $ journalctl -u radarr -f # Ressourcenverbrauch anzeigen $ htop # Speicherplatz prüfen $ df -h /mnt/media
